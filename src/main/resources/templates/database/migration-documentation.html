Initial data migration package

Back to migration

Use this one-time import format only to populate a new accounting dataset. It is not a backup or restore format.

Safety and import process

  • The target accounting domain must be empty. Existing data is never replaced, updated, merged, or deleted.
  • Validation writes no data and produces a preview. Type IMPORT to confirm a validated package within 15 minutes.
  • The confirmed import is one transaction: a failed import rolls back all created records.
  • Disable reference-data seeding before importing: APP_SEED_REFERENCE_DATA_ENABLED=false.

Upload a UTF-8 ZIP file of 20 MiB or less. It must contain exactly the following files, with no directories, duplicate files, or extra entries.

CSV requirements

CSV files use UTF-8, commas, canonical headers in the exact order below, and RFC-style quoted fields. Dates use YYYY-MM-DD; posted_date may be a local ISO date-time. Amounts are non-negative with at most two decimal places, and booleans are lowercase true or false. 

# accounts.csv
source_id,account_number,account_name,account_type,description,is_active

# customers.csv
source_id,name,email,business_name,address,city,province,postal_code,country,business_number,gst_number

# vendors.csv
source_id,name,email,business_name,address,city,province,postal_code,country,business_number,gst_number,qst_number

# invoices.csv
source_id,invoice_number,customer_source_id,invoice_date,due_date,status,subtotal,gst_amount,hst_amount,qst_amount,total_amount,paid_amount,tax_regime,notes

# invoice_lines.csv
source_id,invoice_source_id,line_number,description,quantity,unit_price,total

# bills.csv
source_id,bill_number,vendor_source_id,bill_date,due_date,status,subtotal,gst_amount,hst_amount,qst_amount,total_amount,paid_amount,notes

# bill_lines.csv
source_id,bill_source_id,line_number,expense_account_source_id,description,quantity,unit_price,total

Exporting from QuickBooks Desktop

QuickBooks Desktop exports do not directly match this migration package. Export the source data, then transform it into the required UTF-8 CSV files and manifest.

Migration file QuickBooks Desktop source
accounts.csvLists > Chart of Accounts
customers.csvCustomers > Customer Center
vendors.csvVendors > Vendor Center
invoices.csv / invoice_lines.csvCustomers > Customer Center > Transactions, or Reports > Customers & Receivables
bills.csv / bill_lines.csvVendors > Vendor Center > Transactions, or Reports > Vendors & Payables
journal_entries.csv / journal_lines.csvReports > Accountant & Taxes > Journal or General Ledger
  • Depending on the edition, File > Utilities > Export can export lists or transactions as IIF. IIF files still require conversion before import.
  • Reports can be exported to Excel and used as a source for the conversion.
  • Use the Journal report as the primary source for accounting history. Preserve every balanced debit and credit line.
  • Invoice and bill exports must include all document lines; summary-only reports are insufficient.
  • Menu names and available IIF exports can vary by QuickBooks Desktop edition and version.

Validation rules

  • Account numbers, emails, document numbers, journal numbers, and source IDs must not be duplicated.
  • Invoices and bills require one or more lines. Line totals, subtotals, totals, and paid amounts are validated.
  • Every journal requires at least two balanced lines. Only POSTED and REVERSED journals contribute to general-ledger balances.
  • Text values cannot begin with =, +, -, or @.
